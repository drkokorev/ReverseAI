# ReverseAI — журнал решений

Единый источник правды по принятым решениям. Каждый чат, работающий над проектом, сначала читает этот файл.
Полная спецификация собирается отдельно; здесь — только зафиксированные решения с датой.

Исследование, на которое опираемся: [`docs/research/report.ru.md`](../research/report.ru.md) (2026-10-20).

Чтение (страницы консоли, `status`, `costs`, `ledger-verify`) блокировку не берёт. Блокировку снимает ядро при завершении процесса.
